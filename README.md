# BrightCare Clinic

A modern dental clinic website for **BrightCare Clinic**, built using **React + Vite**.

## Features

* Modern, premium responsive design
* Glassmorphism sticky navigation bar with animated mobile menu
* Services section
* Doctors section
* Patient testimonials
* Clinic gallery
* Appointment booking form
* Google Maps integration
* Floating WhatsApp contact button
* Smooth scroll animations

## Tech Stack

* React
* Vite
* CSS

## Live Demo

This project can be deployed easily on **Vercel**.

## Installation

Clone the repository:

```bash
git clone https://github.com/7umer/dental-clinic-template.git
```

Move into the project folder:

```bash
cd dental-clinic-template
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:5173
```

## Deployment

This project can be deployed easily using **Vercel**.

Steps:

1. Push the project to GitHub
2. Import the repository in Vercel
3. Click **Deploy**
