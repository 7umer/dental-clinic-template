# Clinic Website Template

A modern clinic website built using **React + Vite**.
This template can be customized for different medical clinics such as dental, physiotherapy, pediatric, or skin clinics.

## Features

* Modern responsive design
* Sticky navigation bar
* Services section
* Doctors section
* Patient testimonials
* Clinic gallery
* Appointment booking form
* Google Maps integration
* Floating WhatsApp contact button
* Smooth scroll animations

## Tech Stack

* React
* Vite
* CSS

## Live Demo

This project can be deployed easily on **Vercel**.

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/clinic-template.git
```

Move into the project folder:

```bash
cd clinic-template
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:5173
```

## Deployment

This project can be deployed easily using **Vercel**.

Steps:

1. Push the project to GitHub
2. Import the repository in Vercel
3. Click **Deploy**
